# Replication Package — Mapping public AI-agent repositories on GitHub: clusters and creation-year composition

Replication package for the manuscript:

> **Mapping public AI-agent repositories on GitHub: clusters and creation-year composition**
> Jinkyu Lee, Chang Soo Sung, Joo Yeon Park. Manuscript submitted for publication (2026).
> Archived copy: Zenodo, DOI [10.5281/zenodo.23555409](https://doi.org/10.5281/zenodo.23555409) (release v1.1-peerj; all versions: [10.5281/zenodo.23555408](https://doi.org/10.5281/zenodo.23555408)).

Earlier drafts of the manuscript used the title *Mapping AI-Agent Repositories on GitHub: Clusters, Emergence, and Composition Trends (2016–2025)*.

The study analyzes 9,601 public GitHub repositories related to AI agents (stars ≥ 5, created 2016–2025), collected with a truncation-free procedure, clustered with BGE-M3 embeddings + K-means at two granularities, compared against LDA/NMF/TF-IDF+K-means/BERTopic, and analyzed with binomial GLM trend models (BH-FDR), an emergence taxonomy, and PELT change-point detection with a 30-configuration sensitivity grid.

## Reproducing the analysis

Steps that call local language models or the embedding model need [Ollama](https://ollama.com) and a GPU; every later step runs on a CPU from the files in this repository including `results/embeddings.npy` and `results/emb_keys.npy`.

```bash
# A. CPU-only: reproduce every table of the manuscript from the released files (~15 min)
python audit/score_three_annotators.py          # human annotation statistics (Table 2)
python scripts/analysis_r1_revision.py          # model selection, specification sensitivity, activity, audit by stratum
python scripts/analysis_r2_precision_robustness.py   # precision-weighted and conservative-corpus scenarios
python scripts/analysis_r8_strict_rater_B.py    # strictest-annotator weights
python scripts/r11_reanalysis.py                # R11: weighting, FDR family, misclassification, TF-IDF stability

# B. Full pipeline from collection (GitHub CLI + Ollama + GPU)
python scripts/github_collect.py                # or skip and use data/github_ai_agent_raw_v2.xlsx
python scripts/github_collect_2025fix.py
python scripts/analysis_github_v2.py            # embeddings -> clustering -> baselines -> labels -> GLM -> PELT
python scripts/analysis_domains.py              # application-domain axis + dual-LLM validation
python scripts/audit_kit.py                     # relevance audit sample + dual-LLM labels
python scripts/visuals_jss_r5.py all            # figures
```

Step A was re-run on 2026-10-15 in a fresh copy of this repository: all regenerated tables matched the released files exactly, except one K-means stability median (BGE-M3, k = 5: 0.9717 vs 0.9725) that varies in the fourth decimal with multithreaded floating-point order; every value reported in the manuscript is unchanged (see `results/R11/R11_repro_check.txt`).
The `term_*.py` and `apply_*.py` scripts are manuscript-editing utilities that compare wording against prior-work full texts, which are not redistributed; they are not needed to reproduce any result.

## Data statement

The dataset contains only public GitHub repository metadata (name, description, topic tags, star/fork counts, timestamps, license identifiers) collected via the official GitHub Search API on 2026-08-08. No personal data beyond public repository owner names embedded in repository full names is included.
